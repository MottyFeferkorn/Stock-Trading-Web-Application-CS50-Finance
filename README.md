Stock Trading Web Application — CS50 Finance
Python, Flask, SQLite, SQL, Jinja
- Built a simulated stock-trading application with real-time quote lookup, portfolio valuation, buying/selling, authentication, and transaction history.
- Implemented atomic SQL transactions for stock purchases and sales to maintain consistency between cash balances and transaction records.
- Designed a SQLite trigger to automatically update portfolio holdings from buy/sell transactions, using positive and negative share quantities.
- Used SQL aggregation to calculate current holdings and dynamically retrieve market prices for portfolio valuation.
